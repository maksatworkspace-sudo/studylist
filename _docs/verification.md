# Іске Асыру Және Тексеру

Күні: 2026-10-20. Орта: жергілікті Node.js 24, PGlite PostgreSQL, Next.js.

## Дайын Бөліктер

- Қазақша ашық лента, іздеу, түр/мәртебе/курс/оқытушы сүзгілері.
- Атымен және анонимді жариялау, қонақтың нөмірі мен құпия коды, email арқылы кодты ауыстыру.
- Файлдар: 5 файл және жиынтық 20 МБ, жүктеу барысы, қайта жүктеу, алып тастау, жеке қолжетімділікті тексеру.
- Аккаунтқа тіркелу, email растау және қайта жіберу, кіру, шығу, профиль, құпиясөзді қалпына келтіру.
- Бір деңгей талқылау, өз пікірін өңдеу/өшіру, қолдау, сақталғандар, сілтемені көшіру және құрылғыда бөлісу.
- Оқытушыға 1–5 жұлдыз, бір бағасын жаңарту, ерікті атымен пікір.
- Ресми жауап, мәселені шешу/растау/қайта ашу, ұсыныстың нәтижесі, мәртебе тарихы.
- Себеппен жасыру, қайта көрсету, толық өшіру; жасырылған жазбаның файлдары мен талқылауы көпшіліктен жабық.
- Басшылықтың шақыруы, рөлдер, аккаунтты бұғаттау/қайта қосу, курстар мен оқытушыларды қосу/өңдеу/мұрағаттау.
- Әкімші есебі: түр, мәртебе, курс, оқытушы, орташа рейтинг, шешілу уақыты, күн аралығы, айлық салыстыру, Excel.
- Ішкі хабарламалар, біреуін не бәрін оқылды деп белгілеу.
- Тұрақты email және ИИ кезегі, қайта талпыныс, файлдарды тазалау. ИИ жазба мен әр талқылау пікірін бөлек тексереді; өзі жасырмайды.

## Орындалған Тексерулер

| Тексеру | Нәтиже |
| --- | --- |
| `npm run typecheck` | Өтті |
| `npm test` | 25 тест өтті; HTTP-ге арналған 3 сценарий бөлек орындалады |
| `npm run test:http` | 3 толық HTTP сценарийі өтті |
| `npm run build` | Өтті, барлық беттер мен серверлік бағыттар жиналды |
| `npm audit --omit=dev` | Белгілі осалдық табылған жоқ |
| GitHub | `maksatworkspace-sudo/studylist`, PRIVATE екені тексерілді |

Қамтылғандар: анонимді автордың профилі мен контактілерін жасыру; атымен жарияланған контактіні тек басқаруға беру; қонақ кодының хэші мен бір рет қолданылатын қалпына келтіру; қайталап жіберу; рөл шектеулері; ресми жауаптан кейін өзгертуге тыйым; мәртебелер; қайта ашық мәселенің жабылғандар есебінен шығуы; бірегей рейтинг; бір деңгей талқылау; тікелей SQL оқуға тыйым; CSRF; TLS; каталог пен аккаунттарды басқару; файлдың шегі және басқа браузерге жабық уақытша тіркеме; нақты файлды жүктеп алу; Excel workbook-ты қайта ашу.

Провайдерлердің сәтсіздігі алмастырғыштармен тексерілді: бұзылған ИИ жауабы, хат жеткізілмеуі, кілттер жоқ кезде кезекте қалу, ИИ белгісінің жазбаны автоматты жасырмауы, әр пікірдің жеке тексерілуі және өшірілген пікір белгісінің тазалануы. Бұл нақты провайдердің қазақша сапасын тексеру емес.

Браузерде 1280×720, 390×844 және 320×780 өлшемдері қаралды. Логотип пен фон жүктеледі, бет көлденең шықпайды. Анонимді өтініш жарияланып, құпия коды берілді; басшылық есебі мен басқару тізімі ашылды; жұлдызды өзгерткенде орташа баға жаңарды. Шағын экранда мәзір жиналады, жасырын мәзір фокусқа түспейді, әрекеттер келесі жолға ауысады. Скриншоттар `screenshots/` ішінде.

## Нақты Ортада Қалғандары

1. Vercel және Supabase жобаларын қосу; тариф, деректер аймағы және шығынды иесімен бекіту. Ақылы қызмет сатып алынған жоқ.
2. Нақты PostgreSQL миграциясы, Auth redirect/SMTP, private Storage және Cron/Vault.
3. Алғашқы басшылық: `maksat.workspace@gmail.com`; нақты аты-жөні мен телефон енгізіледі, шақыруды иесі өзі аяқтайды.
4. Gmail авторизациясы және нақты email жеткізу/қайта талпынуды тексеру.
5. ИИ провайдері мен моделін таңдау, кілтті қорғалған ортаға енгізу, қазақша спам мен орынды сын бойынша сапаны тексеру.
6. Нақты Supabase жобасында рөлдер/RLS, қатар сұраныстар, үлкен файл және резервтен қалпына келтіруді тексеру; backup сақтау шегін растау.
7. Кезек қателері мен шығындар мониторингі. Жүктеме артса, лентаға серверлік пагинация/іздеу қажет.

Сайт жергілікті жерде жұмыс істейді. Интернетке жарияланды немесе нақты Gmail/ИИ интеграциясы тексерілді деген тұжырым жасалмайды. Жария ортада демо рөл ауыстыру мен жергілікті растау токендері берілмейді.
